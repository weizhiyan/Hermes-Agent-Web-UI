# 表达增强 Skill

用于把零碎、口语化、未成体系的内容补充完善、统一结构并增强表达。

## 适用场景

- 文案润色、表达优化、标题优化、结构梳理。
- 需求说明、问题反馈、产品方案、分享稿、汇报内容。
- 将零散想法整理成更清晰、更专业、更有说服力的文本。

## 工作方式

1. 先保留用户原始观点、立场和语气，不擅自改变事实。
2. 补全缺失背景、逻辑链路、例子、结论和行动项。
3. 统一标题层级、段落结构、术语和语气。
4. 根据场景输出：自然版、专业版、短版、分享版、需求版。
5. 对不确定信息使用占位或提示，不替用户编造事实。

## 输出标准

- 结构清晰，层次明确，可直接复制使用。
- 信息更完整，但不啰嗦、不空泛。
- 重点更突出，减少重复表达。
- 必要时给出「原问题 → 优化方向 → 改写结果」。

## 边界

- 不改变用户核心立场。
- 不过度营销化。
- 不把所有内容都写成广告文案。
- 不替代产品方案、代码实现或生图提示词专家职责。
