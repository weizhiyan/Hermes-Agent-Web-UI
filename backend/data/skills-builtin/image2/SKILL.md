# image2 生图方法论

用于 WebUI / Hermes Agent 的图像生成、图生图、提示词优化与结果兜底。

核心原则：先锁定不能变的，再给 AI 发挥空间。

## 工作流程

1. 先理解用户真正要生成或编辑什么，不要直接堆风格词。
2. 找出不能改变的内容：人物/IP/品牌/产品外观/参考图结构/布局/业务含义。
3. 找出必须保留的信息：主体、动作、道具、场景、文字要求、尺寸用途。
4. 明确允许优化的范围：构图、光影、材质、氛围、清晰度、商业质感。
5. 补充风格参考和输出标准：UI、图标、插画、海报、产品图、IP 形象等。
6. 明确禁止项：不要多余文字、不要水印、不要无关 logo、不要改变主体身份。

## 通用提示词结构

[主体与专有名词], [服装/道具/动作], [场景], [构图], [风格], [光影], [色彩], [质量要求]

## 专有名词规则

- 不要把用户指定的 IP / 品牌 / 产品泛化成普通描述。
- 如果知道英文名，可以保留中英文，例如：Anya Forger (阿尼亚), from Spy x Family。
- 如果不确定英文名，不要编造，保留用户原文。

## 图生图 / 二次编辑规则

如果用户上传参考图或选择图片二次编辑：

- 保持原主体、身份、构图和视觉连续性。
- 只修改用户本轮指定的部分。
- 不要默认把上一张图作为参考，除非用户明确选择或上传。
- 可使用表达：Maintain the original subject and composition, only change ...

## WebUI 工具协作

当用户明确要生成图片、出图、画图、改图、修图、生成海报/插画/头像/产品图时，应优先调用 WebUI 图片生成工具：

webui_image_generate

调用时传入优化后的 prompt，同时保留 sourcePrompt 为用户原始需求。不要只输出提示词而不执行生图。

## 默认负向约束

除非用户明确需要，否则避免：low quality, blurry, watermark, text, logo, distorted hands, extra fingers, deformed face, messy composition。
