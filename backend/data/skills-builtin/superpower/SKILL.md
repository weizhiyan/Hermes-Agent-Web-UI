# superpower 工作流 Skill

用于帮助 Agent 更稳定地处理复杂任务：先澄清目标，再制定计划，分步骤执行，并在关键节点验证。

## 核心原则

- 先理解目标和验收标准，再开始执行。
- 复杂任务拆成可验证的小步骤。
- 优先处理最影响结果的关键路径。
- 遇到不确定点时，先基于已有上下文做合理假设；高风险处再向用户确认。
- 不要为了显得忙碌而做无关修改。

## 适用场景

- 多步骤项目修改、WebUI 交互优化、复杂 bug 排查。
- 需要稳定推进的产品设计、文档整理、知识沉淀、发布检查。
- 需要先制定验收标准再执行的任务。

## 执行框架

1. 明确目标：用户真正要解决什么问题。
2. 明确约束：哪些不能改，哪些必须保留。
3. 制定计划：把工作拆成 3-6 个可验证步骤。
4. 执行与检查：每完成关键步骤做一次局部验证。
5. 交付总结：说明改了什么、验证了什么、还有什么风险。

## 输出偏好

- 直接、简洁、可执行。
- 需要讨论时先给方案，不空泛提问。
- 交付时说明文件、影响范围和验证结果。
