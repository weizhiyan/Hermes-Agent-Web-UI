# GitHub Release Template

## v1.0.0

### 项目简介

Hermes Agent WebUI 是一个本地优先的 AI WebUI，这个版本主要围绕聊天区、Markdown 预览、思考过程、工具调用、记忆、技能、分身和模型管理做了整理和优化。

### 这一版做了什么

- 聊天区更清晰，消息流、思考块、工具调用块分层展示。
- 右侧 Markdown 预览更顺手，支持历史文件和版本查看。
- 消息操作区改成图标按钮，喜欢 / 不喜欢 / 复制更直观。
- 视觉风格统一成黑白极简，更适合长期使用。
- 安装方式补齐到 Windows、PowerShell、Shell、Docker Compose。
- 新增版本历史和安装说明，方便用户直接下载和部署。

### 安装方式

- Windows：`start.bat`
- PowerShell：`start.ps1`
- Linux / macOS：`start.sh`
- Docker：`docker compose up --build`

### 版本说明

- 当前版本说明见 `CHANGELOG.md`
- 安装说明见 `docs/INSTALLATION.md`
- 如果你要给别人下载，建议把本页内容直接复制到 GitHub Release 描述里
