# GitHub Release Template

## v1.0.0

### 这一版做了什么

- 统一并规范 Hermes WebUI 的整体视觉语言，偏向黑白极简风格。
- 优化右侧 Markdown 预览交互，拖拽更顺手，并移除冗余提示。
- 重做消息操作区，统一图标按钮和反馈样式。
- 改进思考块与工具调用块展示，更接近 Claude / Codex 的轻量结构。
- 补齐跨电脑安装方式：Windows、PowerShell、Shell、Docker Compose。

### 安装方式

- Windows：`start.bat`
- PowerShell：`start.ps1`
- Linux / macOS：`start.sh`
- Docker：`docker compose up --build`
