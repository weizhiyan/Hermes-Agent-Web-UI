# Hermes 记忆系统 AI 指南

本文档给后续接手 Hermes Agent WebUI 的 AI 使用。目标是让 AI 知道：哪些文件是长期核心记忆，哪些文件是对话记忆，如何把原始聊天压缩成可用上下文，以及什么时候应该更新核心记忆。

## 1. 记忆文件位置

核心记忆目录：

```text
C:\Users\Administrator\Desktop\Hermes Agent\backend\data\memory\core
```

当前核心文件：

```text
AGENTS.md       Hermes Agent 的身份、行为边界、协作方式
PROFILE.md      用户画像、长期工作方式、沟通偏好
PREFERENCES.md  UI、交互、输出、验收等偏好规则
TOOLS.md        本项目工具、路径、接口、数据位置
```

对话记忆目录：

```text
C:\Users\Administrator\Desktop\Hermes Agent\backend\data\history-md
```

对话记忆是聊天导出的 Markdown 原文。它们默认不应该全量塞进模型上下文，而应该先压缩成结构化摘要。

用户指定文件目录：

```text
默认不固定。用户可能会要求读取某个具体文件或目录，例如：
C:\Users\Administrator\.copaw\workspaces\default\memory\2026-03-26.md
D:\某个项目\memory\xxx.md
```

处理原则：

- 如果用户明确给了文件路径，优先读取用户指定文件，不要只看 Hermes 默认目录。
- 如果用户给的是目录，先列出目录下的 Markdown / JSON / 文本文档，再按用户目标选择相关文件。
- 如果用户没有指定路径，默认读取 Hermes 的核心记忆目录和对话记忆目录。
- 用户指定的外部文件可以作为参考样例，但不要自动搬进核心记忆，除非用户明确要求或内容确实是长期规则。

## 2. AI 读取原则

- 优先读取核心记忆，因为它是长期稳定规则。
- 对话记忆只在当前任务相关时读取，不要无差别加载全部历史。
- 读取对话记忆时，先看文件名、月份、摘要，再决定是否打开原文。
- 对话记忆要压缩成短上下文后再使用，避免把长聊天流水直接塞进 prompt。
- 如果发现用户新的长期偏好、固定工作方式或重要项目规则，应建议写入核心记忆。

## 3. AI摘要是什么

小脑瓜页面中的“AI摘要”不是删除原文，也不是人工总结替代原文。

它的作用是：

- 把很长的聊天 Markdown 压缩成 AI 更容易读取的上下文。
- 保留用户偏好、关键结论、待办事项、重要路径等高价值信息。
- 过滤工具协议、长 JSON、重复问候、无意义流水，减少上下文噪音。
- 让后续 AI 不用每次都读完整聊天记录，也能快速理解这段记忆的重点。

页面交互建议：

- `AI摘要`：默认给 AI 和用户快速查看重点。
- `预览`：查看原始 Markdown 的渲染效果。
- `原文`：查看原始 Markdown 文本，便于排查或复制。

## 4. 对话记忆压缩模板

把一篇原始对话 Markdown 压缩为以下结构：

```markdown
# 对话标题

## 文件信息
- 文件地址：完整路径
- 更新时间：YYYY-MM-DD HH:mm

## 用户偏好与长期信号
- 用户明确表达的偏好
- 用户不喜欢的交互或输出方式
- 可复用到未来任务的工作风格

## 关键结论与上下文
- 本次对话真正确定下来的方案
- 已经完成的改动或决策
- 重要路径、配置、接口、文件名

## 待办与后续动作
- 尚未完成的事
- 需要验证的点
- 下一位 AI 接手时应该先做什么

## 原文摘要
- 用 1 到 3 条概括原始对话内容
```

## 5. 什么时候写入核心记忆

适合写入核心记忆：

- 用户长期偏好，例如“尽量用中文写文档，便于其他 AI 接手”。
- 反复出现的产品原则，例如“频道和网关不要重复概念”。
- 稳定路径和数据结构，例如“小脑瓜核心记忆在 backend/data/memory/core/”。
- 高价值协作规则，例如“验收要模拟真实用户操作，不要只看代码”。

不适合写入核心记忆：

- 一次性的临时 bug。
- 已经过期的任务状态。
- 大段原始聊天记录。
- 不确定、未确认的猜测。

## 6. 小脑瓜页面验收标准

- 页面必须显示文件的真实完整路径。
- 核心记忆可以编辑、保存、取消。
- 对话记忆默认展示 AI摘要，同时保留原始 Markdown 预览和原文。
- 左侧文件列表和右侧内容应像一个整体工作区，通过线条区分区域，不要堆太多卡片背景。
- 深色模式和浅色模式都必须使用主题变量，不要写死白色背景。

## 7. 接口说明

```text
GET /api/memory
读取记忆概览：核心文件、对话文件分组、统计、路径。

GET /api/memory/core/:id
读取核心记忆文件。

PUT /api/memory/core/:id
保存核心记忆文件。

GET /api/memory/conversation/:id
读取对话记忆原文和压缩后的 compactContent。
```

## 8. 给 AI 的执行建议

当用户要求“继续优化记忆”时：

1. 先打开本指南。
2. 再打开 `AI引导/小脑瓜页面验收与改造方案.md`。
3. 检查 `/api/memory` 是否能返回核心记忆和对话记忆。
4. 对页面做真实点击验收：切换核心文件、进入编辑、取消、保存、切换对话记忆、切换精简/预览/原文。
5. 如果发现对话记忆压缩不够好，优先改 `backend/services/memory.js` 里的压缩逻辑。
