# Hermes 本地 Markdown 预览与分类指南

最后更新：2026-05-12。

这份文档给后续接手 Hermes Agent WebUI 的 AI 使用，说明右侧 Markdown 预览和小脑瓜记忆页如何读取本地 MD 文件。

## 预览边界

- 右侧 Markdown 预览只预览“输出文件”或本地历史 MD 文件。
- 普通聊天气泡内容不要直接塞进右侧预览，避免用户误以为它已经落盘成文件。
- 如果当前对话没有 Artifact 或本地 Markdown 文件，点击预览按钮应显示空状态，提示用户可到“历史文件”里打开本地 MD。

## 数据来源

- WebUI 对话导出的 Markdown 默认在 `backend/data/history-md/`，只属于聊天归档和小脑瓜记忆页。
- 右侧预览的“历史文件”不是聊天归档，它读取独立的 Agent 输出库。
- Agent 输出库默认目录是 `backend/data/output-md/`。
- 用户也可以在设置页的“MD 输出库目录”指定任意允许目录，例如 `C:\Users\Administrator\Documents\HermesMD`。
- 右侧预览接口是 `GET /api/system/md-library`，读取文件内容仍使用 `GET /api/system/file-content?path=...`。
- 如果 Agent 输出文章、报告、方案、教程等 Markdown，应优先写入 Agent 输出库，而不是写入 `history-md`。

## 分类方式

- “全部”视图：默认按 `mtime` 倒序展示，最新文件在前。
- “按类型”视图：后端会读取 frontmatter，也会根据文件名和正文关键词兜底推断类型。
- “按文件夹”视图：用户在输出库中新建一级文件夹，前端会自动识别成分类。
- “按标签”视图：如果 Markdown frontmatter 有 `tags` 或 `tag`，前端会自动显示标签 Tab。
- 当前预留类型包括：`文章`、`方案`、`报告`、`教程`、`会议纪要`、`代码文档`、`视觉设计`、`其他`。

推荐在 Markdown 顶部写 frontmatter，方便 WebUI 精准分类：

```md
---
title: Hermes 语雀接入方案
type: 方案
tags: [语雀, 集成, API]
summary: 说明语雀 Token、仓库列表读取和安全命令确认的处理方式。
---
```

## 摘要要求

- 每个 MD 文件列表项至少展示：标题、日期、内容概括、类型。
- 概括要服务检索，不追求长，优先提炼“用户要求 / 已做结论 / 后续动作”。
- 如果没有 `summary`，后端会用正文第一段进行轻量兜底。

## 交互要求

- 卡片主按钮是“预览”，次按钮是“打开文件”。
- 点击标题等同于预览。
- 预览后应进入独立预览态，顶部有“返回”按钮，底部不再露出卡片列表。
- “打开文件”应调用系统打开文件位置，而不是只显示路径。
- 右侧预览只预览真实文件或 Artifact，不要把普通聊天气泡当成本地文件预览。

## 给 Agent 的落盘建议

- 写文章、报告、方案、总结、教程时，优先保存为 `.md` 文件，并放在 Agent 输出库。
- 如果用户没有指定目录，使用 `backend/data/output-md/`。
- 如果用户指定了目录，遵循用户指定目录，但仍要避免写入敏感系统目录。
- 文件名建议使用 `YYYY-MM-DD_主题.md`，例如 `2026-05-12_语雀绑定方案.md`。
- 内容较长时必须包含标题、摘要、日期和类型，便于前端列表展示。
