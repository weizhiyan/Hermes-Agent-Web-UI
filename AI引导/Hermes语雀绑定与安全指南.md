# Hermes 语雀绑定与安全指南

这份文档给后续接手 Hermes Agent WebUI 的 AI 使用，用来安全地接入语雀或类似知识库服务。最后更新：2026-05-11。

## 定位

语雀绑定属于“知识库 / 工具集成”，不是模型网关，也不应该放在频道网关里混用。建议后端提供独立的集成配置和代理 API，前端只显示连接状态、知识库列表、同步结果和最近错误。

## 安全规则

- 不要在对话、Markdown 导出、日志、截图里输出真实 Token、API Key、Cookie、Password。
- 不要执行 `curl | bash`、`curl | sh`、`curl | python` 这类下载后直接执行的命令。
- 调试接口时优先走后端封装，例如 `/api/integrations/yuque/*`，由后端统一加认证头并做脱敏。
- 如果必须在终端手动请求接口，只能使用明确的 `https://` URL，并把响应保存为临时 JSON 后人工查看，不要 pipe 给解释器执行。
- 用户曾经在聊天中贴过语雀 Token。任何接手 AI 都应建议用户轮换该 Token，并避免再次要求用户明文粘贴到对话里。

## 推荐接入流程

1. 在设置页保存语雀配置：`baseUrl`、`authType`、`token`、`userId`。Token 只保存在本机后端数据文件，不回显原文。
2. 后端提供“测试连接”：请求 `GET /api/v2/user` 或用户指定资源，返回账号名称、状态码、错误摘要。
3. 后端提供“获取知识库”：请求 `GET /api/v2/users/{userId}/repos`，返回仓库 id、名称、更新时间。
4. 前端允许用户勾选要同步的知识库，不自动全量拉取。
5. 同步内容写入 `backend/data/knowledge/yuque/` 或用户指定目录，并维护索引文件，记录来源 URL、同步时间、文件路径。
6. 对话调用知识库时只注入必要摘要，不把完整文档长期塞进上下文。

## WebUI 交互建议

- 连接失败时展示“原因 + 下一步”，例如 Token 无效、权限不足、网络失败，不展示完整请求头。
- 显示 Token 时只显示前后少量字符或统一显示 `[已隐藏]`。
- 每次同步后写入可查看日志，但日志必须脱敏。
- 语雀同步和模型配置分开，不要让用户误以为语雀是模型 Provider。

## 对 Agent 的提示词建议

当用户要求“绑定语雀”时，请先判断当前环境是否已有后端集成。如果没有，优先实现后端安全代理和前端配置，不要直接让用户执行含 Token 的 curl 命令。若需要验证接口，请使用本机后端进行测试，并确保输出前调用脱敏函数。
